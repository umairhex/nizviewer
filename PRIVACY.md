# NizViewer privacy policy

Last updated: August 29, 2026

NizViewer is a browser extension that displays job information already available to your browser while you use Indeed.

## Data collection

NizViewer does not collect, sell, or transmit personal information to a NizViewer server. The extension does not require a NizViewer account and does not include advertising or analytics code.

## Local storage

The extension stores preferences and a temporary cache of extracted job information in local browser extension storage. Cached fields can include a job key, posting date, company name, salary text, work setup, experience, job type, degree, technologies, benefits, perks, age limit, and gender when those values are present or detected in a listing.

Users can clear cached job information from the NizViewer settings popup. The cache also expires old entries automatically.

## Network access

NizViewer runs on supported Indeed domains. When a search card contains only a short snippet, the extension can request the corresponding public Indeed job-detail page to extract the complete description. These requests go to the same Indeed site the user is visiting.

NizViewer does not send extracted job data to an external NizViewer API.

## Permissions

- `storage` saves extension preferences and the local job cache.
- Indeed host permissions let the extension read supported Indeed pages and request public job-detail pages on those sites.

## Third-party services

Indeed controls the content and availability of its pages. Indeed's own privacy policy applies to data exchanged directly with Indeed. NizViewer is an independent project and is not affiliated with or endorsed by Indeed.

## Source and contact

The extension source is available at [github.com/umairhex/nizviewer](https://github.com/umairhex/nizviewer). Questions and privacy reports can be submitted through the repository's issue tracker.
