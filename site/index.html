How it works

Where the Indeed posting date comes from

NizViewer reads job data that Indeed sends to your browser. It checks structured page data and network responses for the listing identifier and publication timestamp. When a search card contains only a short snippet, the extension requests that job's public /viewjob?jk=... page and parses the complete description.

The extension does not invent missing values. A card reports whether its data is full, partial, pending, or failed. Expanded cards also identify fields that were not detected, because an omitted requirement is different from a confirmed requirement.

Privacy and trust

Your extracted job data stays in browser storage

NizViewer does not require an account and does not send extracted job details to a NizViewer server. It stores a temporary cache through the browser's local extension storage so repeated visits do not need to parse the same listing again.

The source code is public. NizViewer is an independent project and is not affiliated with or endorsed by Indeed. Always confirm salary, eligibility, and application requirements in the original job posting.

Frequently asked questions

Questions about Indeed job dates and NizViewer

How can I see the real posting date on Indeed?

Install NizViewer and open an Indeed landing page, search page, or individual job. When Indeed provides a publication timestamp, NizViewer shows the calendar date and the number of days since posting on the job card.

Does NizViewer require me to click every job card?

No. Search and landing-page cards can fetch their public job detail pages automatically, with limited concurrent requests and retry handling.

Can it show the technology stack for an Indeed job?

Yes. NizViewer scans the complete description for mentioned technologies and groups recognized terms into categories such as frontend, backend, cloud, DevOps, data, AI, security, mobile, and testing.

Why is a field marked "not detected"?

The job description may not state that information, or it may use language the current parser does not recognize. NizViewer reports missing data instead of treating it as a confirmed value.

Is NizViewer free?

Yes. NizViewer is free to install and its source code is publicly available on GitHub.

Does NizViewer work on Indeed Pakistan?

Yes. The extension supports pk.indeed.com through its Indeed domain permissions. It also supports several other regional Indeed domains.
